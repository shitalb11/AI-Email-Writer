# 🤖 AI Email Writer

An AI-powered Email Writer that helps users generate professional, context-aware email replies using **Google Gemini AI**. The project consists of a **React frontend**, **Spring Boot backend**, and a **Chrome Extension** for seamless email generation directly from the browser.

---

## ✨ Features

- 🤖 Generate professional email replies using AI
- 💻 Modern and responsive React user interface
- ⚙️ Spring Boot REST API backend
- 🌐 Chrome Extension integration
- 📋 Copy generated email with one click
- 🚀 Fast and easy-to-use interface

## 🚀 Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/shitalb11/AI-Email-Writer.git
```

### 2️⃣ Backend Setup

```bash
cd Backend
mvn spring-boot:run
```

### 3️⃣ Frontend Setup

```bash
cd Frontend
npm install
npm run dev
```

### 4️⃣ Chrome Extension Setup

1. Open Google Chrome
2. Go to `chrome://extensions/`
3. Enable **Developer Mode**
4. Click **Load unpacked**
5. Select the **Extension** folder
